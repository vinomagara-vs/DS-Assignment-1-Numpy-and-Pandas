# DS-Assignment-1-Numpy-and-Pandas
**Overview**
This project demonstrates the fundamental concepts of NumPy and Pandas for data manipulation, exploration, and analysis. The assignment covers working with 1-dimensional arrays, 2-dimensional arrays in NumPy then Pandas Series, and Data Frames to perform common data science operations.

**Objectives**
Understand NumPy array creation and manipulation.
Perform operations on 1D and 2D arrays.
Learn indexing, slicing, reshaping, and aggregation techniques.
Explore Pandas Series and DataFrame structures.
Conduct basic data cleaning and exploratory data analysis (EDA).
Generate meaningful insights from structured datasets.

**Topics Covered**
**NumPy**
1D Array Operations
Array creation
Indexing and slicing
Mathematical operations
Statistical functions (mean, max, min, sum)
Array filtering
2D Array Operations
Row and column selection

**Pandas**
Series Manipulation
Creating Series
Accessing elements
Filtering data
Applying functions
Handling missing values
DataFrame Manipulation
Creating DataFrames
Reading and writing data
Selecting rows and columns
Sorting and filtering
Grouping and aggregation
Data cleaning
Summary statistics
Exploratory Data Analysis (EDA)

**The project includes:**
Dataset inspection
Statistical summaries
Missing value analysis
Data filtering and transformation
Aggregation of key metrics
